# ChordTrack

Akkordfolge in der Zeitleiste: Akkordspur oben, Akkordnamen im Clip, Klang im Clip-Kopf.

- **Akkordspur:** 26 px unter dem Lineal, Kopf „Akkorde · C Dur“, je Akkord ein Chip mit Name und Stufe (C I, G V, Am vi, F IV) am Takt. Sie zeigt die Tonart des Projekts und folgt einem Tonartwechsel.
- **Akkord-Clip:** Unter dem Clip-Kopf steht je Takt der Akkord, getrennt durch Linien in Spurfarbe; darunter die Noten.
- **Clip-Kopf:** rechts der Klang in Versalien (STREICHER, E-BASS, E-PIANO).
- Die drei erzeugten Spuren heißen nach ihrer Rolle und haben aufeinanderfolgende Spurfarben.
- **MIDI-Spur im Spurkopf:** Eingang zeigt das MIDI-Gerät (Klaviatur-Symbol), nie „Mikrofon“.
