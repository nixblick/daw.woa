# JingleWizard

Assistent „Jingle bauen“: sechs Schritte, je Schritt eine Frage, Zusammenfassung unten.

- **Schrittleiste:** Vorlage · Beat · Akkorde · Stimme · Schluss · Fertig. Erledigte Schritte mit Haken, aktueller gefüllt in `accent`.
- **Fragen** als große Wahlkarten mit Symbol (fröhlich, seriös, Nachrichten, Party) oder als Segmentschalter (5 s · 10 s · 30 s).
- **Fußzeile:** die bisherige Wahl in einer Zeile (`font-mono`), Zurück und Weiter.
- **Fertig:** Export in Jingle-Ordner, Bibliothek und Cart-Wall.
