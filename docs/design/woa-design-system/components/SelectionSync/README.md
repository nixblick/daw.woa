# SelectionSync

Eine Auswahl gilt überall: Spurkopf, Kanalzug und Insert-Rack zeigen immer dieselbe Spur.

Klick auf Spurkopf, Kanalzug, einen Clip oder „fx n“ wählt die Spur. Die Darstellung ist überall gleich:

- Fläche: Spurfarbe 14 % auf `panel`, im hellen Thema genauso.
- Rahmen: 1 px Spurfarbe. Der Rack-Kopf hat zusätzlich eine 3-px-Oberkante.
- Spur in der Zeitleiste: 6 % auf `well`.
- Clip-Auswahl: 2-px-Rahmen in `text`. Clips sind schon spurfarbig, darum ist der Rahmen neutral und maximal kontrastreich.
- Nie `accent` für Spurauswahl; `accent` bleibt Playhead, Modus und eingeschaltete Schalter.
