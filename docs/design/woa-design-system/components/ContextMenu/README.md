# ContextMenu

Kontextmenü (Rechtsklick) für Spurkopf, Kanalzug und Clip.

- **Eintrag:** Symbol 16 px, Text, Tastenkürzel rechts in `font-mono`, Höhe 28 px, Hover `surface`.
- **Gruppen:** durch Trennlinien; Reihenfolge: Bearbeiten (Umbenennen, Farbe, Duplizieren) → Funktionen → Löschen.
- **Gefahr:** „Löschen“ steht immer allein als letzter Eintrag, Text und Symbol `on-air`, Hover 14 % Rot.
- **Nicht verfügbar:** 40 % Deckkraft, bleibt sichtbar (keine springenden Menüs).
- **Rahmen:** `panel`, Rahmen `border-strong`, Radius `radius-xl`, Polster 4 px.
- **Listen mit Suche** (z. B. „+ Effekt“): Suchfeld oben, Abschnittstitel in `panel-label`.
