# ScreenParty

Entwurf 1920 × 1030: Party mit deiner Playlist.

Seite, kein Baustein.

- **Oben:** zwei Decks mit Plattenteller, Status, Titel, Restzeit, Play/Pause, Wellenform.
- **Darunter:** Auto-Übergang und Zufall als Schalter, Crossfader.
- **Party-Pult:** drei Gruppen.
- **Playlist** mit „läuft“ und „als Nächstes“, Ordner laden und Vollbild im Kopf.
- **Rechts:** Bibliothek, Wunschliste (Eingabe + Wunsch), Fernbedienung mit QR, Adresse, PIN, Handyzahl und OSC-Schalter.
- **Ohne Grün:** keine grünen Vollflächen; Play leuchtet in der Modusfarbe.
