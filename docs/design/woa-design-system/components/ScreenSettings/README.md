# ScreenSettings

Einstellungen als Fenster (1400 × 930): großer Filter oben, Bereiche links (248 px, 38 px je Eintrag, aktiv `accent-soft` + Kante), rechts Gruppen-Karten mit Zeilen „Name + Erklärung | Bedienelement“ (min. 56 px).

Bereiche: Allgemein · Audio · Sendung & Shoutcast · MIDI · Klang & Bänke · KI · — · Entwickler · Über. Chips zeigen Zustand (KI an, Entwickler aus). Speichern geschieht sofort, Stand-Zeile „gespeichert · Uhrzeit“.
