# InsertRack

Insert-Rack im Studio-Dock rechts: alles, was das Signal der gewählten Spur durchläuft, von oben nach unten in Signalfluss-Reihenfolge.

- **Kopf:** Farbpunkt, Name, Art („Audio“ · „MIDI“ · „Bus“ mit Symbol), Spur-Menü (⋯). Fläche und Oberkante wie die Auswahl.
- **Eingang:** Quelle (Auswahlfeld) und Trim in dB.
- **Inserts · n:** Slots (`EffectSlot`) in Signalreihenfolge. Rechts im Titel „Alle umgehen“ (Umschalt+B). Am Ende „+ Effekt“ öffnet die Liste: Suche, Eingebaut, Plugins, Plugin-Ordner.
- **Sends:** pro Zeile Ziel-Bus, Pegel in dB, Entfernen (bei Hover); darunter „+ Send“.
- **Ausgang:** Ziel (Master oder Bus) und Pan.

Leer-Zustände:

- **Kein Projekt-Track:** Symbol, „Keine Spur“, ein Satz, Knopf „+ Spur“ (Strg+T).
- **Spur ohne Effekte:** nur „+ Effekt“.

Gruppen ohne Inhalt (Sends) zeigen nur ihren „+“-Knopf. Breite 320–340 px.
