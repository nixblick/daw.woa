# SettingsFilter

Filter der Einstellungen (Strg+,).

- Tippen zeigt sofort eine Trefferliste über alle Bereiche: Symbol · Name (Treffer markiert, `accent-2` 35 %) · Beschreibung · rechts Bereich mit Pfeil. Bereiche ohne Treffer werden links gedimmt.
- ↑/↓ wählt, Enter springt in den Bereich und markiert die Zeile (`is-hit`, Kante `accent-2`) für 2 s. Esc leert den Filter.
