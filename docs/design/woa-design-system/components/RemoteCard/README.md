# RemoteCard

Fernbedienungskarte im Party-Modus.

- **Groß** (Fensterhöhe ≥ 900 px): QR-Code, Adresse, PIN, Handyzahl, OSC-Schalter.
- **Kompakt** (< 900 px): eine Zeile mit QR 64 px, Adresse · PIN, Handyzahl, „QR groß“ und „An“.
- **QR groß:** Klick auf den QR, das Symbol oder Taste Q zeigt ihn 300 px groß über der Party-Ansicht, damit Handys ihn aus Abstand lesen. Klick oder Esc schließt.
