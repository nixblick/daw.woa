# ChannelKeys

Kanaltasten Mute, Solo, PFL und Rec-Arm als feste Vierergruppe pro Kanal.

Reihenfolge immer M · S · PFL · ●. Farben fest, modusunabhängig: Mute `on-air` (gefüllt), Solo `warn` (gefüllt), PFL `cue` (leuchtend `is-lit`), Rec-Arm `on-air` (leuchtend, blinkt während der Aufnahme). Größe `woa-key--sm woa-key--sq`, Abstand `space-2`.

- Buchstaben auf den Tasten bleiben, Farbe allein reicht nicht.
- PFL schaltet auf den Vorhör-Ausgang (Kanal 3/4), nie auf den Sendebus.
