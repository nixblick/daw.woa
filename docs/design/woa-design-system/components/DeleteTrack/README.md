# DeleteTrack

Spur löschen: ein Papierkorb, keine Rückfrage, dafür Rückgängig.

- **Der eine Papierkorb** sitzt im Spurkopf, rechts in Zeile 1. Sichtbar bei Hover und an der gewählten Spur, Platz immer reserviert.
- **Weitere Wege, kein weiterer Knopf:** Rechtsklick auf Spurkopf oder Kanalzug → „Spur löschen“, oder Entf bei gewählter Spur.
- **Danach** erscheint unten mittig über der Zeitleiste ein Hinweis: „Spur „Name“ gelöscht · Rückgängig (Strg+Z)“, 8 s mit ablaufendem Strich, Schließen mit ×/Esc. Mehrere: „3 Spuren gelöscht“.
- Rückgängig stellt alles wieder her: Clips, Effekte, Sends, Routing.
