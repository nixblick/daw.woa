# StatusPill

Beleuchtete LED-Pille für Zustände wie DECK LÄUFT, MIKRO OFFEN, REC, STREAM, MIDI.

`<span class="woa-pill woa-pill--ok is-active">`. Varianten `--ok`, `--cue`, `--rec`, `--warn`, ohne = Modusfarbe. `is-blink` für laufende Aufnahme. Text in Versalien, Monospace.

- Eine Pille = ein Zustand, nie ein Knopf.
- Inaktiv bleibt sie sichtbar (graue LED), damit das Layout nicht springt.
