# SoundPicker

Instrument einer MIDI-Spur: eigener Abschnitt „Instrument“ im Insert-Rack, zwischen Eingang und Inserts.

- **Zu:** eine Kachel mit Rollen-Symbol in Spurfarbe, Klangname, „Rolle · Bank“, Probeton (P), Aufklappen.
- **Auf:**
  - Rollen Lead · Bass · Pad · Kit als Segmentschalter.
  - Je Rolle vier Klänge als Kacheln mit Probeton.
  - Darunter die Klangbank (eingebaut oder nachladbar, mit Größe) und „Eingebauter Synth“.
- Die Rolle ist beim Erzeugen gesetzt (Akkorde = Pad, Bass = Bass, Arpeggio = Lead, Beat = Kit), der Klang lässt sich jederzeit tauschen.
- Kein Klang-Auswahlfeld zwischen den Effekten: Instrument ist kein Insert.
