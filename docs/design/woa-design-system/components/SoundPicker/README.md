# SoundPicker

Instrument einer MIDI-Spur: Abschnitt „Instrument“ im Insert-Rack, zwischen Eingang und Inserts. Geöffnet über den Instrument-Knopf im Spurkopf.

- **Suche** (32 px) über alle 31 Klänge; Treffer zeigen die Kategorie.
- **Kategorien** Klavier · Bass · Gitarre · Streicher · Bläser · Synth · Drums · Alle (4 × 2 Segmente mit Symbol) – statt der Rollen Lead/Bass/Pad/Kit. Die Rolle bleibt intern für Akkord- und Jingle-Bau.
- **Kacheln:** Name + Vorhören; Probeton läuft = Lautsprecher `cue`. Gewählt = `accent-soft` + Rahmen.
- **Herkunft der Bank** als Kasten: Name, eingebaut/geladen, Anzahl, Lizenz, Urheber, Taste „Bank“ (.sf2 laden).
- **Synth (einfach)** bleibt ganz unten wählbar; alte Projekte behalten ihn.
- Kein Klang-Auswahlfeld zwischen den Effekten: Instrument ist kein Insert.
