# DjMixer

DJ-Mixer zwischen den Decks: je Deck ein Kanal, in der Mitte Master und Kopfhörer, unten der Crossfader.

- **Kanal** (Kante und Fläche in Deckfarbe), von oben nach unten:
  - Trim
  - Hi, Mid, Lo (Mitte = 0 dB, ganz links = Kill)
  - Filter (links Tiefpass, rechts Hochpass)
  - Cue-Taste (Kopfhörer-Symbol, leuchtet `cue`)
  - Kanalfader mit Stereo-LED-Kette
- **Mitte:**
  - Master-LED-Kette und Master-Pegel.
  - Kopfhörer: Mix (links nur Cue, rechts nur Master) und Pegel.
- **Crossfader** mit A/B in Deckfarben, Kurve „weich | hart“ als Segmente.
- **Drehregler sind hier richtig:** Ein DJ-Mixer ist so gebaut. Im Produzenten-Kanalzug bleibt es ohne Regler.
- **Kopfhörer** hören auf dem Vorhör-Ausgang (Kanal 3/4, wie PFL im Radio). Ist keiner eingerichtet, sind die Cue-Tasten gesperrt; der Tooltip sagt, wo man ihn einrichtet.
