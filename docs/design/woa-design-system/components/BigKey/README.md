# BigKey

Party-Großtaste (88 px, große Radien) für Bedienung per Touch und aus Distanz.

`button.woa-bigkey` mit optionalem Icon, `is-on` gefüllt in `accent`, `woa-bigkey--alt` in `accent-2`, `is-pulse` pulsiert im Beat.

- Pro Bildschirm höchstens 6 Großtasten.
- Beschriftung ein Wort, Versalien, `display-l`-Familie.
