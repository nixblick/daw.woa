# JingleVoice

Jingle-Assistent, Schritt 4 „Stimme“.

- **Wer spricht?** `Frei (lokal) | ElevenLabs`; rechts Credit-Chip.
- Textfeld (14/20), Stimmen als Kacheln (Name, Art, Hörprobe), drei Regler Stabilität · Ähnlichkeit · Stil (0–100 %).
- „Effekt erzeugen“ (Beschreibung → Geräusch) und „Bett erzeugen“ (Stimmung + Länge aus Schritt 1).
- **Datenschutz** fest sichtbar bei ElevenLabs: „Text geht an ElevenLabs. Keine Namen, Telefonnummern …“.
- **Kostenkasten:** geschätzte Credits + Aufschlüsselung, Abbrechen, Erzeugen (`ok`). Lädt: Kreisel, Schritt x von n, Balken, Abbrechen. Fehler: Grund + Ausweg, „Erneut“.
- Bei „Frei“ entfallen Credits, Datenschutz und Kostenkasten.
