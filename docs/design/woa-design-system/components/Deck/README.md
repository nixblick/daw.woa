# Deck

Party-Deck in der Ansicht „Einfach“: Plattenteller, Titel, BPM-LCD, Wellenform mit Beatgrid, eine Großtaste Play/Pause.

- Play pulsiert im Beat (`--beat` = 60/BPM s); ohne Analyse kein BPM-LCD und ein gleichmäßiger Puls.
- Cue, Sync, Hot Cues, Loop und Tempo gibt es nur in der DJ-Ansicht (`DjDeck`).
