# Deck

DJ-Deck für den Party-Modus: Jogwheel, BPM-LCD, Wellenform mit Beatgrid und Großtasten.

`.woa-deck` mit `.woa-jog` (`is-paused` stoppt die Drehung), `.woa-bpm`, `canvas.woa-wave` (`data-played`, `data-beats`) und `.woa-deck__keys`.

- Play pulsiert im Takt (`is-pulse`, `--beat` = 60/BPM s).
- Zwei Decks nebeneinander, Crossfader mittig darunter.
