# Logo

WOA-Logo: fünf LED-Säulen in W-Form mit ON-AIR-Lampe, als Wortmarke, App-Icon und Favicon in Dunkel und Hell.

Assets in `assets/Logos/`. Auf dunklem Grund `*-dark.svg`, auf hellem `*-light.svg`. In der App zeichnet `WOA.mark()` die Marke mit der Modusfarbe.

- Schutzraum: eine Säulenbreite rundum. Mindestgröße Bildmarke 20 px, darunter Favicon.
- Die Lampe bleibt immer rot, die Säulen nie umfärben außer in Modusfarbe.
