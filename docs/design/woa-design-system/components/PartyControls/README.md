# PartyControls

Party-Pult: alle Party-Befehle als Großtasten in drei Gruppen, eine Tastengröße.

- **Abspielen:** Zurück · Play/Pause · Stopp · Weiter.
- **Springen:** Von vorn · −10 s · +10 s · Wiederholen.
- **Lautstärke:** Leiser · Anzeige (LCD mit Balken und dB) · Lauter · Stumm.
- **Modus-Schalter** (Auto-Übergang, Zufall) stehen links neben dem Crossfader in `accent-2`.
- **Zustand nur über Füllung:** Play läuft = `accent` gefüllt und pulsiert im Beat; eingeschaltete Schalter = `accent-2` gefüllt. Sonst neutral.
- Tastenhöhe 64 px, vier Spalten, Gruppentitel in `panel-label` mit Linie.
- Keine Status-Texte unter den Tasten („Lautstärke +0 dB“ steht in der Anzeige).
