# RadioLevels

Pegelgruppe im Radio-Modus: alle Quellen als Kanalzüge, dann Master, dann die Ausgänge.

- **Quellen:** Playlist, Carts, Decks, Mikro. Je ein Fader, LED-Kette und Scribble-Strip in eigener Spurfarbe, keine Drehregler.
- **Master:** nur die Stereo-LED-Kette.
- **Ausgänge:** Monitor (Kopfhörer, Notebook) und Stream, je mit Fader und Stumm-Taste.
- Gruppen durch 1-px-Linien getrennt, alles in einer Karte; Faderweg 130 px.
- Die Werte sind dieselben wie im Einstellungen-Dialog und per MIDI-Learn steuerbar.
