# ChannelStrip

Mischpult-Kanalzug ohne Drehregler: Kanaltasten M/S/PFL, Fader mit Stereo-LED-Kette und Scribble-Strip.

`.woa-strip` mit `--t` (Spurfarbe) – von oben: Kanaltasten (`.woa-keys`), Fader + Meter (`__fm`), Name (`__name`, oben Spurfarben-Kante).

- Keine Drehregler im Kanalzug. Gain, EQ, Pan und Sends gehören ins Insert-Rack bzw. in den Kanal-Inspektor.
- Breite 92 px, Master ganz rechts.
- Im Radio-Pult mit „On“-Taste statt Mute.
