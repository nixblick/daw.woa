# DjWaves

Parallele Wellenformen beider Decks über die volle Breite, die Mittellinie ist „jetzt“.

- Oben Deck A, unten Deck B, je in Deckfarbe; Beatgrid-Striche am oberen Rand.
- Dazwischen die Phasenanzeige: Punkt in `ok`, wenn die Schläge übereinander liegen, daneben die Abweichung in ms.
- Markierung links: Deck, BPM und „(Sync)“, wenn Sync an ist.
- Höhe 150 px; scrollt mit der Wiedergabe, Mausrad zoomt.
