# Timeline

Arrangement-Zeitleiste mit Spurköpfen, Audio- und MIDI-Clips, Takt-Lineal und Playhead.

`.woa-arr` (Spalten 250 px + Zeitleiste). Spurkopf `.woa-th` mit `--t`, Spur `.woa-lane`, Clip `.woa-clip` (`--t`, Kopf `__h`, Wellenform-`canvas data-woa-wave`), Auswahl `is-sel`, Playhead `.woa-playhead`.

- Clip-Fläche = Spurfarbe 22 % auf `well`, Kopf voll.
- Playhead immer `accent` des Modus.
