# ScreenPartyDJ

Entwurf 1920 × 1030: Party in der Ansicht „DJ“.

Seite, kein Baustein. Aufbau:

- **Ansichtsleiste:**
  - Einfach | DJ.
  - Auto-Übergang, im DJ-Modus aus.
  - Hinweis auf den Kopfhörer-Ausgang.
  - Ordner laden, Vollbild.
- **Parallele Wellenformen** mit Phasenanzeige.
- **Decks und Mixer:** Deck A, Mixer, Deck B (gespiegelt).
- **Unten:**
  - Playlist mit BPM, Tonart und „in Deck A/B laden“.
  - Wunschliste und Fernbedienung kompakt.

Die Ansicht „Einfach“ bleibt der Standard (`ScreenParty`); DJ ist ein Umschalter, keine eigene Betriebsart.
