# MixerBus

Mixer-Reihe: Spuren · Busse · „+ Bus“ · Master, Gruppen durch 1-px-Linien getrennt.

- **„+ Bus“** ist ein gestrichelter Platzhalter, 64 px breit, volle Kanalzug-Höhe, direkt links vom Master (Strg+Umschalt+T). Ein neuer Bus erscheint an seiner Stelle, der Platzhalter rückt nach.
- **„fx n“** unter den Kanaltasten zeigt die Zahl der Effekte; Klick wählt die Spur und zeigt das Insert-Rack. 0 = gedimmt, Fehler = rot mit Warnsymbol.
- **Gewählter Kanalzug:** Fläche 14 % und Rahmen in Spurfarbe (wie Spurkopf).
