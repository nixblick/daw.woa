# Transport

Transport-Konsole des Produzenten: Hardware-Tasten, Timecode-LCD, Eingangspegel, REC-Pille.

`.woa-transport` mit `.woa-keys` (Zurück, Play `--ok`, Stopp, Aufnahme `--rec`, Loop), LCD mit `.woa-tc` (Takt und Zeit, `lcd-l`) und horizontaler LED-Kette.

- Play leuchtet grün gefüllt, Aufnahme rot leuchtend, scharf blinkend.
- Leertaste = Play/Stopp, R = Aufnahme, L = Loop.
