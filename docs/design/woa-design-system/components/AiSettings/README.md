# AiSettings

Einstellungen → KI → ElevenLabs.

- Kopf: Symbol `user-sound`, Titel, Zustandschip (nicht eingerichtet · prüfe · verbunden `ok` · Schlüssel ungültig `warn`).
- Schlüsselfeld 36 px, Mono, nur letzte 4 Zeichen sichtbar. Tasten: **Eintragen** (leer), **Prüfen**, **Entfernen** (Symbol, danger, fragt nach).
- Credits als LCD: übrig groß, Balken, „von 30.000 · Abo“, Erneuerung.
- Fehler: Meldung von ElevenLabs in `warn` direkt unter dem Feld.
- Hinweis (`woa-privacy`, Rahmen `cue`): Schlüssel im System-Schlüsselbund, Texte gehen an ElevenLabs.
