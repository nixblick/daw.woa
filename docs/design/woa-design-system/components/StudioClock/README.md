# StudioClock

Radio-Studio-Uhr mit 60 Sekunden-LEDs, 12 Stundenpunkten und Digitalzeit in der Mitte.

`<div class="woa-clock" style="--d:220px">`; `WOA.init()` baut Punkte und Zeit. `data-time="20:59:51"` friert ein (für Doku/Tests). Leuchtfarbe `lcd-ink`.

- Gehört in den Radio-Modus neben das Sende-Deck; Größe 150–240 px.
- Sekundenkranz läuft von oben im Uhrzeigersinn voll – wie die klassische Studiouhr zum Ranfahren an die volle Stunde.
