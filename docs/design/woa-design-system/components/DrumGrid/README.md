# DrumGrid

Drum-Raster: 16 Schritte je Takt, eine Zeile je Instrument des Kits.

- **Zeilen:** Kick, Snare, Clap, Hi-Hat zu, Hi-Hat offen, Becken. Je Zeile Farbkante, Name, Vorhören.
- **Schritte** in Vierergruppen mit wechselnder Fläche, Zählzeiten 1–4 darüber.
- **Bedienung:** Klick = laut (volle Farbe mit Leuchten), Umschalt+Klick = leise (halbe Farbe), Rechtsklick = löschen.
- **Lauflicht:** Rahmen in `text` um den aktuellen Schritt.
- **Kopf:** Muster (Pop, Four on the Floor, Rock, Hip-Hop, …) und Länge in Takten.
