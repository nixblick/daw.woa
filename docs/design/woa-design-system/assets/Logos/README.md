# Logos

Bildmarke: fünf LED-Säulen, deren Oberkanten ein W zeichnen, darüber die ON-AIR-Lampe. Abgeleitet vom bisherigen App-Icon (`packaging/linux/icons/de.wironair.woa.svg`).

- `woa-wordmark-dark.svg` / `-light.svg`: Marke + „WOA“ (O = ON-AIR-Lampe) + „WIR ON AIR“. Website-Kopf, Splash, About. Dunkel: Säulen `#ff9838`, Schrift `#ecf0f8`. Hell: Säulen `#c45f00`, Schrift `#161a22`.
- `woa-icon-dark.svg` / `-light.svg`: App-Icon (256 px, Kachel). Linux-Icon, MSI, Flatpak.
- `woa-mark-dark.svg` / `-light.svg`: Bildmarke ohne Kachel, für eigene Flächen.
- `woa-favicon-dark.svg` / `-light.svg`: 32 px, volle Säulen statt Segmente. Website, Tab, Taskleiste.
- Die Lampe ist immer Rot (`on-air`). Schriftzüge sind in Pfade umgewandelt (Barlow Condensed 800/600).
