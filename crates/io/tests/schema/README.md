# DAWproject schema

`Project.xsd` is the DAWproject 1.0 schema from the open-source DAWproject repository
(MIT licence, Copyright (c) 2020 Bitwig); the licence text is in `LICENSE` next to it.
It is used only by `tests/dawproject.rs` to check that exported `project.xml` files are
valid (skipped when `xmllint` is not installed).
